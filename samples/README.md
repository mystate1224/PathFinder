# samples —— 演示用素材

这批文件是给你手工点页面时用的，不需要预先导入任何东西。**页面右上角的「演示例子」按钮**
可以一键运行这些素材（走 `backend/services/demo.py`），不必手动上传。

## 一、文本素材（对应不同抽取规则）

| 文件 | 用在哪 | 看点 |
| --- | --- | --- |
| `机器学习导论课件.md` | 资料库上传，分类选**课件** | 解析 → 分块 → 课件规则集抽知识点，一条龙 |
| `教师论文-多模态检索增强.md` | 同上，分类选**论文** | 论文规则集优先抓研究方法术语 |
| `教学设计-注意力机制.md` | 同上，分类选**教案** | 教案规则集围绕教学目标与重难点 |
| `实习岗位-检索方向.md` | 同上，分类选**岗位** | 岗位规则集抽技能型知识点，服务就业匹配 |
| `作业样本-优.md` / `作业样本-待改进.md` | 批改中心试批 / 批量批改 | 建议分 A 档 vs C 档的对比 |

## 二、图片素材（3 张，由 `tools/make_samples.py` 生成）

图片是**刻意造出来**的：里面同时有"要学的正文"和"该被清掉的噪声"，
否则去杂规则一条都命中不了，演示就变成了看不出它在干什么。

| 文件 | 看点 |
| --- | --- |
| `课件扫描页.png` | 页眉 / 页码 / 水印 / 目录点线 / 表格 / 定义句 —— 去杂与课件规则集一起验证 |
| `手写作业.png` | 手写答案 + 红笔批注 + 轻微倾斜与噪点，测视觉批改与作业规则集 |
| `论文截图.png` | 摘要 / 关键词 / 方法段 / 公式，测论文规则集 |

想改素材：改 `tools/make_samples.py` 顶部的文案重新跑即可（需要 Pillow 与 Windows 中文字体）。

## 三、怎么用「试批」

打开「批改中心 → 试批」，把 `作业样本-优.md` 的内容复制粘贴进文本框（或点页面上的
示例按钮），填好课程与满分后点「生成建议分」。**试批不落库**，只返回建议分、等级与
评语，可以反复试。

## 注意

- 文本素材是纯文本，不是真实教学资料，只用于验证链路跑得通。
- 图片素材由脚本合成，内容真实可读，但没有真实扫描件的复杂版面。
- **未配置视觉模型（`LLM_VISION_MODEL`）时，图片会被如实标记"本次未真正读图"**，
  这是设计内的降级行为，不是故障；配好 Key 后会自动切换为真实读图。
- 上传大小上限默认 8 MB（`.env` 的 `MAX_UPLOAD_MB`）。
