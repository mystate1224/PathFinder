# samples —— 演示用素材

这四份文件是给你手工点页面时用的，不需要预先导入任何东西。每一份对应一条能力，
在下面的页面里直接选文件上传即可。

| 文件 | 用在哪 | 看点 |
| --- | --- | --- |
| `机器学习导论课件.md` | 「资料与知识库 → 上传资料」，分类选**课件** | 走完「图文素材解析 → 知识点结构化抽取 → 索引入库」，在「知识点」与「检索」两个子页里能看到结果 |
| `教师论文-多模态检索增强.md` | 同上，分类选**论文** | 抽取出的知识点会带研究方法类术语，适合用来试混合检索（BM25 + 向量 + RRF） |
| `作业样本-优.md` | 「批改中心 → 试批」或「按作业批改」 | 建议分应落在 A 档，评语会指出结构完整、有推导 |
| `作业样本-待改进.md` | 同上 | 建议分应落在 C 档，评语会指出缺少推导与结论 |

## 怎么用「试批」

打开「批改中心 → 试批」，把 `作业样本-优.md` 的内容复制粘贴进文本框（或点页面上的
示例按钮），填好课程与满分后点「生成建议分」。**试批不落库**，只返回建议分、等级与
评语，可以反复试。

## 怎么用「批量批改」

「批改中心 → 批量批改」支持一次上传多个文件，把 `作业样本-优.md` 和
`作业样本-待改进.md` 一起选进去，就能看到同一次批改里两份作业的等级差异。

## 注意

- 这些文件都是纯文本，不是真实的教学资料，只用于验证链路跑得通。
- 上传大小上限默认 8 MB（可用 `.env` 里的 `MAX_UPLOAD_MB` 调整）。
- 没有配置视觉模型（`LLM_VISION_MODEL`）时，图片类作业会被标记为「需人工批改」，
  这是设计内的降级行为，不是故障。
