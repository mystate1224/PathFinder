# RAG 路由测试题（五种架构各一组）

这份素材专门用来验收「先路由、再执行」：**同一个问题换一种问法，应该走不同的 RAG。**
路由判错了，后面再好的检索也是白查，所以这里把判据写死。

用法：在答疑页把策略选成「自动选择」，逐条提问，看答案上方的策略徽标是否与下表一致；
也可以把策略手动切到某一项，对比同一问题在五种架构下的差异（演示时很好用）。

## 判据一览

| 架构 | 什么时候走 | 命中信号 |
| --- | --- | --- |
| 混合式 RAG | 概念、原理这类文字解释 | 「什么是 / 为什么 / 解释 / 原理」 |
| 图谱 RAG | 问关系、前置、知识链路 | 「关系 / 关联 / 先学 / 前置 / 链路」 |
| 智能体式 RAG | 要结合我的情况、要计划 | 「结合我 / 帮我规划 / 给我建议 / 对比分析」 |
| 纠错型 RAG | 口语、指代、说得含糊（含 ≤9 字且无明确对象） | 「那个 / 这个 / 它 / 到底 / 为什么不」 |
| 多模态 RAG | 问图、表、扫描件、版面 | 「图里 / 图上 / 那张 / 扫描 / 截图 / 第 N 页」 |

## 混合式 RAG（期望 strategy = hybrid）

Q: 什么是反向传播？
Q: 解释一下为什么需要注意力机制
Q: 准确率和召回率有什么区别？

## 图谱 RAG（期望 strategy = graph）

Q: 注意力机制和 Transformer 有什么关系？
Q: 缩放点积注意力和多头注意力有什么关系？
Q: 学知识图谱之前需要先掌握哪些基础？
Q: 过拟合和正则化是什么关系？

## 智能体式 RAG（期望 strategy = agentic）

Q: 结合我的情况给我一个复习计划
Q: 帮我规划一下这学期的学习安排
Q: 根据我的画像，给我一些建议
Q: 对比一下学业型和就业型的发展路径

## 纠错型 RAG（期望 strategy = corrective）

Q: 那个到底为什么不work？
Q: 也就是说，它为什么会发散？
Q: 通俗讲
Q: 上面说的那个能再解释一下吗？

## 多模态 RAG（期望 strategy = multimodal）

Q: 课件里那张图说明了什么？
Q: 第 5 页的表格里写了什么？
Q: 论文截图里的关键结论是什么？
Q: 手写作业的照片里老师批了什么？

## 手动指定（演示对比用）

把策略下拉框切到指定项，再用同一句话提问，观察差异：

- 同一句「什么是梯度下降？」分别走 hybrid / graph / agentic / corrective / multimodal；
  hybrid 给概念解释，graph 会额外给出知识点子图，agentic 会先规划再答，
  corrective 会显示首查质量与改写过程，multimodal 会同时列出图片素材。

## 注意

- 路由是**规则版**（断网可用），判据就在 `backend/services/ragroute.py` 的 `_ROUTE_PATTERNS` 里；
  想让模型自己挑，把 `resolve()` 换成 `route_llm()` 即可，前端与调用方都不用改。
- 五种架构的检索结果都保持同构（`ref / content / via / fused_score`），
  所以答案与引用卡不需要为某一种架构单独改。
