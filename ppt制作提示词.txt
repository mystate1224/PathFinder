【使用说明】
1. 把「一、全局风格设定」作为系统级/前置提示词，一次性锁定风格；
2. 「三、逐页提示词」按页喂给工具（或交给设计师逐页排版）；
3. 文中「◆」开头的是视觉/版式指令，「」内的是可直接上页面的文案；
4. 页码较原始草稿做了两处合理化：补充第 5 页目录页；AI 能力说明按
   「教师 / 学生」拆成两页（13、14），后续页码顺延，总计 18 页。

───────────────────────────────────────────────
一、全局风格设定（前置提示词，先生成再逐页）
───────────────────────────────────────────────
请生成一套「新锐科技感 Pitch Deck」风格的路演 PPT，共 18 页，16:9 横版。

◆ 设计语言（严格遵循，参考现代极简 Pitch Deck 模板）：
- 底色：纯白 / 极淡雾白，大量留白，禁止深色底、禁止渐变满铺；
- 标题：超大号黑色无衬线粗体（思源黑体 / HarmonyOS Sans / 阿里巴巴
 普惠体），左对齐，每页主标题控制在 1~3 行，字号为全页最大；
- 顶部导航条（每页统一）：左侧品牌名「PathFinder 寻径」，中间 4 个
  小号灰色菜单词（简介 / 赛题 / 技术 / 团队），右侧年份「2026」；
- 小节标签样式：一个荧光黄绿小圆点 + 全大写小号字距加宽的引导词，
  例如「● PROJECT PATHFINDER」；
- 主色：宝蓝 #4353FF（大标题强调、实色卡片、按钮）；
  辅色：青绿 #17C9A8（次级卡片、正向数据）；
  点缀：荧光黄绿 #D6F94B（圆形徽章、圆点标签、下划线高亮）；
  文字黑 #111111，正文灰 #555555；
- 卡片：大圆角（16~24px）实色卡片，蓝卡配白字、绿卡配白字/黑字，
  卡内放「大数字 + 小标签」，避免长段落；
- 按钮/徽章：胶囊形；黑色小圆形内白色箭头「→」是标志性元素，
  出现在按钮和徽章左侧；
- 装饰元素（每页至多 2 种，克制使用）：一条极细的浅灰曲线贯穿版面、
  淡色坐标纸/网格图案方块、星号「✳」几何符号、黄绿圆形小徽章；
- 数据表达：大号数字（如 89%、4.9+）放在蓝/绿实色卡上，白字加粗；
- 禁止：emoji 图标、立体阴影、照片墙、密排长文、艺术字。

◆ 统一页脚：左下角「PathFinder · 寻径教育」，右下角页码。

───────────────────────────────────────────────
二、可直接复用的项目事实素材（填页时取用，不要编造）
───────────────────────────────────────────────
- 产品名：寻径 PathFinder——高校「学业—就业双轨智能导航平台」，
  多模态教学智能体 Web 应用；
- 六大 AI 能力：①图文素材智能解析 ②知识点结构化抽取 ③交互式分层
  答疑 ④教师智能备课 ⑤作业智能批改 ⑥教师 Copilot；
- 五条业务链路：学生画像 · 师生匹配 · 交互答疑 · 资源广场 · 作业；
- 五种 RAG 检索架构自动路由：混合式 / 图谱式 / 智能体式 / 纠错型 /
  多模态——系统按问题意图自动选择，纠错型支持两轮检索自我修正，
  图谱式返回可视化知识子图，答案全部标注出处、可溯源；
- Agent 能力：上传资料入知识库；一键生成复习提纲 / 错题卡 / 阶段
  小结，生成结果附引用清单；支持新开对话 / 回到任意一次历史对话；
- 双引擎设计：真实大模型 + 规则引擎兜底，返回结构完全一致，界面
  常显「AI 生成 / 规则生成」徽标——断网无 API Key 也能完整演示；
- 分层理念：分层只用于「推荐内容深度与任务难度」，坚决不做分班 /
  分层教学，所有输出挂免责提示（体现教育公平立场，答辩可讲）；
- 技术栈：Python FastAPI + SQLite(WAL+FTS5 全文检索)；前端原生
  HTML/CSS/JS，零构建零框架；自研 LangChain 同构组件，零框架依赖；
  51 项全链路自动化测试 + 真实浏览器逐页巡检。
