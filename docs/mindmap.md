# 寻径教育 PathFinder · 系统能力清单

> 按**能力**组织，不按页面数量：先分教师端 / 学生端两支，每支再分「基础能力」与「特色功能」。
> 图文解析、知识抽取、交互答疑是两端共有的基础能力；其余为各端特色。

## 教师端　—— 教 · 评 · 管

### 一、基础能力（两端共有）

- **图文解析**　上传讲义 / 试卷（PDF、Word、图片），转成可编辑文本与结构
- **知识抽取**　自动抽取知识点并入库，后续可检索、可复用
- **交互答疑**　多轮追问 + 溯源标注，答案可存为笔记

### 二、特色功能

- **分层智能备课**　按学生层次生成教案（目标 / 重难点 / 环节）与可编辑 PPT
- **个性化指导方案**　基于学情画像，给出团队组建与任务安排建议
- **智能作业批改**　AI 给建议分与评语，教师确认后生效，支持批量试批与成绩导出
- **教学资源匹配**　推荐候选学生、管理团队名额与方向、发布企业资源、批复学生申请
- **教学 Copilot**　一句话完成查学生 / 备课 / 讲知识点，意图自动路由

## 学生端　—— 学 · 问 · 长

### 一、基础能力（两端共有）

- **图文解析**　题目 / 资料拍照即解析，快速转成可读内容
- **知识抽取**　抽取要点，沉淀进个人资料库，随时回查
- **交互答疑**　随时提问，按自己的层次获得讲解，答案一键存笔记

### 二、特色功能

- **分层答疑**　同一个问题按层次给出不同深度的讲解与练习
- **画像与成长路线**　五维能力雷达 + 阶段任务打卡，看清自己往哪走
- **团队与资源申请**　接收推荐团队、申请企业项目资源、跟踪申请进度
- **作业闭环**　在线作答 / 传附件，回看得分与教师评语
- **个人知识库**　自有素材入库建索引，并导入教师共享资料

## 两端共用的技术底座

- **双引擎**　规则版 + 真实模型，失败自动降级，断网也能演示
- **六格矩阵**　学业型 / 事业型 × A / B / C，决定推荐内容的深度与任务难度
- **混合检索**　BM25 + 向量双路召回，RRF 融合，命中标注来源
- **五种 RAG**　混合 / 图谱 / 智能体 / 纠错 / 多模态架构，自动路由可手切
- **数据隔离**　学生之间互不可见，教师共享须显式授权导入
- **演示账号**　教师 `teacher`、学生 `stu01`，密码统一 `123456`

---

**分层口径**：平台产出的分层结论只用于决定「推荐内容的深度」与「任务难度」，不用于分班、不构成准入门槛；批改环节的 AI 只给**建议分**，最终分由教师确认。
