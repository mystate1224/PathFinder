# 寻径教育 PathFinder · 系统能力清单

- **教师端**
  - **基础功能**
    - **图文解析**　讲义 / 试卷上传即转文本
    - **知识抽取**　自动抽知识点入库，可检索
    - **交互答疑**　多轮追问 + 溯源标注
  - **特色功能**
    - **分层智能备课**　按层次生成教案与 PPT
    - **个性化指导方案**　学情画像 → 团队与任务建议
    - **智能作业批改**　AI 建议分 + 评语，教师确认
    - **教学资源匹配**　团队组建、企业资源、申请批复
    - **教学 Copilot**　一句话查学生 / 备课 / 讲知识点

- **学生端**
  - **基础功能**
    - **图文解析**　拍照即解析
    - **知识抽取**　要点沉淀进个人资料库
    - **交互答疑**　随时提问，答案存笔记
  - **特色功能**
    - **分层答疑**　同一问题按层次给不同深度
    - **画像与成长路线**　五维雷达 + 阶段任务打卡
    - **团队与资源申请**　推荐团队、项目申请、进度跟踪
    - **作业闭环**　在线作答，回看得分与评语
    - **个人知识库**　素材入库 + 导入教师共享

- **两端共用的技术底座**
  - **双引擎**　规则版 + 真实模型，断网可演示
  - **六格矩阵**　学业 / 事业 × A / B / C，定深度与难度
  - **混合检索**　BM25 + 向量双路召回
  - **五种 RAG**　混合 / 图谱 / 智能体 / 纠错 / 多模态
  - **数据隔离**　学生互不可见，共享需授权
  - **演示账号**　teacher / stu01，密码 123456

> 分层只用于决定推荐内容深度与任务难度，不用于分班；AI 只给建议分，最终分由教师确认。
