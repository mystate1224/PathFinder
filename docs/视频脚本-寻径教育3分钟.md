# 寻径教育 PathFinder · 3 分钟介绍演示视频脚本

> 用途：对外展示用的一条主视频。**只讲核心功能与关键技术**，不讲部署、不讲安装。
> 总时长 **180 秒**（±3 秒）。风格：**简约大方**，蓝白为主，节奏前松后紧，最后一段走情绪。

---

## 0. 视觉与听觉基线（全片统一）

| 项 | 取值 | 说明 |
|---|---|---|
| 画面 | 1920×1080 / 30fps，浏览器缩放 100% | 录屏区留 8px 圆角与浅描边，像卡片而不是裸窗口 |
| 主色 | 宝蓝 `#4353FF`、青绿 `#17C9A8`、荧光黄绿 `#D6F94B`（仅点缀） | 与产品同一套设计令牌，别临时换色 |
| 底色 | 蓝雾白 `#f6f9ff`，纯白卡片 `#ffffff`，描边 `#dce6f2` | 保持通透，不要深色科技风 |
| 主字体 | 思源黑体 / 微软雅黑，标题 Bold，正文 Regular | 数字用等宽感（如 `71/71`）会更"工程" |
| 转场 | **统一用"线条"当转场动机**：上一段的线甩出画面 → 下一段的线从同方向进入 | 全片唯一的"特效"，其余一律硬切/淡入 |
| BGM | 单钢琴或柔和电子铺底，80–95 BPM；00:00–00:16 轻，演示段压到 -6dB，02:38 起抬起来 | 无歌词 |
| 字幕 | 底部安全区内，白字 + 40% 深蓝描边；关键词（混合式 / 图谱式 / 双引擎）用品牌色高亮 | 关键词高亮不要超过每屏 2 个 |
| 出镜 | 无人出镜，全程界面录屏 + 动效包装 | 需要"人"的感觉时用手部光标移动代替 |

## 3. 剪辑注意

1. **演示段别加速**：答疑与备课这两段是 credibility 的来源，1.0 倍速播；
   只有能力快切（H）允许 2 倍速。
2. **每屏只留一个重点**：技术段的架构图一屏只亮一个标签，别一次性全亮。
3. **不要旁白念字幕**：字幕是关键词，旁白是解释，两者互补不重复。
4. **诚实口径必须出现**：分层 caveat（00:24）与引擎徽标（01:45）这两处不能剪掉，
   它们是这个项目最值钱的部分——**知道自己不做什么**。
5. 片尾留白 1 秒再黑场，情绪才落得下来。
