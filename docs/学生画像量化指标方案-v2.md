## 0. 一页纸结论

| 问题 | 结论 |
|---|---|
| 现有五维能代表学业/就业能力吗 | **不能**。专业基础、自驱与 GPA 相关系数 **0.990 / 0.995**，五维几乎无独立信息；沟通维标准差仅 **0.31**（几乎恒定）。雷达图的"形状"基本由 GPA 一个数和两个自评值决定 |

## 1. 现状诊断：为什么必须重建

### 1.1 证据一：五维与 GPA 高度共线（实测 72 人）

用 `student_profiles.ability` 实测相关矩阵：

|  | GPA | 专业基础 | 实践 | 科研 | 沟通 | 自驱 |
|---|---|---|---|---|---|---|
| **GPA** | 1.000 | **0.990** | −0.589 | 0.915 | −0.882 | **0.995** |
| 专业基础 | | 1.000 | −0.683 | 0.958 | −0.924 | 0.981 |
| 实践 | | | 1.000 | −0.845 | 0.885 | −0.539 |
| 科研 | | | | 1.000 | −0.969 | 0.886 |
| 沟通 | | | | | 1.000 | −0.852 |
| 自驱 | | | | | | 1.000 |

各维标准差：专业基础 0.48、实践 0.49、科研 1.30、**沟通 0.31**、自驱 0.35。

读法：专业基础与自驱跟 GPA 的相关是 0.99 / 0.995——**它们就是 `gpa/20` 加一个常数**；沟通维标准差 0.31、跨度只有 0.8 分，在雷达图上几乎不动。所以这张图看上去是五个独立能力，实质是一个数的变形。

### 1.2 证据二：循环论证

现有链路（`stratify.py`）：

```
research_intent / job_intent（自评）
   → diff ≥ 0.5 ? → 定 track（学业型 / 事业型）
        → track 决定 ability_vector 用哪套公式
             → 学业型：research = base+0.3+…、practice = base−0.6+…
             → 事业型：practice = base+0.4+…、research = base−1.2+…
                  → 雷达图呈现"学业型科研高 / 事业型实践高"
```

问题：**主标签先于能力分数被决定**，能力分数又用来"证明"主标签。学生自评填一个 4 分，系统就会给他画出一个"科研维凸起"的雷达图，然后告诉他"你是学业型"。这不是测评，是回声。

此外自评本身还有两个已知缺陷：① 学生对"科研""就业"的想象往往与实际不符（大一尤其明显）；② 自评可被随意修改，且系统允许改完立即重算画像。

### 1.3 证据三：五维缺乏外部效度

`foundation / practice / research / communication / driveself` 这五个词是项目自造的，无法回答评委必然会问的两个问题：

- "凭什么是这五个维度？" —— 没有外部依据。
- "分数 4.2 是什么意思？" —— 没有行为锚定，无法与任何公认标准对齐。

## 2. 权威框架对标

新六维的每一维都必须能指到一个公开、可查的权威出处。三套框架分工如下：

### 2.1 学业侧：CEEAA 工程教育认证通用标准 12 条毕业要求

中国工程教育专业认证协会（CEEAA）标准，与《华盛顿协议》（Washington Accord）毕业生素质要求（Graduate Attributes）实质等效，是国内工科专业**唯一具有国际互认效力**的能力框架。12 条中可观测的 5 条被本方案采用：

| 编号 | 毕业要求 | 本方案的对应维度 |
|---|---|---|
| 1 | 工程知识：将数学、自然科学、工程基础和专业知识用于解决复杂工程问题 | **D1 知识掌握** |
| 2 | 问题分析：应用基本原理，识别、表达并通过文献研究分析复杂工程问题 | **D2 分析推理** |
| 4 | 研究：基于科学原理采用科学方法研究，包括设计实验、分析与解释数据 | **D4 研究创新** |
| 5 | 使用现代工具：开发、选择与使用恰当的技术、资源、现代工程工具和信息技术工具 | **D3 工具实践** |
| 9/10 | 个人和团队 / 沟通：在多学科团队中承担角色；与同行及公众有效沟通 | **D5 协作沟通** |
| 12 | 终身学习：具有自主学习和终身学习的意识与能力 | **D6 自主发展** |

（第 3、6、7、8、11 条——设计开发解决方案、工程与社会、环境与可持续发展、职业规范、项目管理——本平台**无对应证据源**，故不纳入，见第 11 节局限说明。）

### 2.2 就业侧：人社部八项职业核心能力 + NACE 八项职业胜任力

**人社部《国家技能振兴战略》（1998）八项职业核心能力**——国内官方职业核心能力标准，分方法能力与社会能力两类：

| 人社部八项 | 本方案对应 |
|---|---|
| 自我学习 | D6 自主发展 |
| 信息处理 / 数字应用 | D3 工具实践 |
| 与人交流 / 与人合作 | D5 协作沟通 |
| 解决问题 | D2 分析推理 |
| 创新革新 | D4 研究创新 |
| 外语应用 | *（暂无证据源，不纳入）* |

**NACE Career Readiness Competencies（2021 修订版）八项**：Career & Self-Development、Communication、Critical Thinking、Leadership、Professionalism、Teamwork、Technology（第八项 Equity & Inclusion 官方标注"正在审查中"，国内高校场景不适用，**明确排除**）。对应同上：Critical Thinking→D2、Technology→D3、Teamwork + Communication→D5、Career & Self-Development + Professionalism→D6。

### 2.3 难度标尺：Bloom 修订版认知层级

记忆 → 理解 → 应用 → 分析 → 评价 → 创造。

用途不是加一个维度，而是给证据**加权**：学生问"什么是梯度下降"（记忆层）与"梯度下降为什么会在鞍点卡住"（分析层）对 D2 的贡献必须不同。方案中所有文本类证据都按 Bloom 层级打系数：记忆/理解 0.6、应用 1.0、分析/评价 1.3、创造 1.5。

### 2.4 自驱维度的理论依据

D6 对应人格心理学中 **尽责性（Conscientiousness，大五人格之一）**，它是与学业表现最稳定的非智力预测因子（元分析结果相关量级约 0.2，属小到中等效应）。因此 D6 只能作为**辅助维度**，权重不得高于知识与分析类维度——这也是下文把 D6 权重压在 0.25 以内的原因。

## 3. 新六维指标体系

| 维度 | 名称 | 定义（行为锚定） | 权威出处 | 归属 |
|---|---|---|---|---|
| **D1** | 知识掌握 | 课程知识的掌握广度与牢固程度 | CEEAA-1；Bloom 记忆/理解 | 学业三件套 |
| **D2** | 分析推理 | 识别问题、拆解、用原理推演并判断结论的能力 | CEEAA-2；NACE Critical Thinking；人社部 解决问题 | 学业三件套 |
| **D3** | 工具实践 | 选择与使用现代工具、把方案落地为可运行产物的能力 | CEEAA-5；NACE Technology；人社部 数字应用/信息处理 | 事业三件套 |
| **D4** | 研究创新 | 设计实验/方案、分析数据、提出改进与原创想法 | CEEAA-4；人社部 创新革新 | 学业三件套 |
| **D5** | 协作沟通 | 在团队中承担角色、与他人协调、清晰表达 | CEEAA-9/10；NACE Teamwork/Communication；人社部 与人交流/与人合作 | 事业三件套 |
| **D6** | 自主发展 | 自我规划、按时履约、主动积累与复盘 | CEEAA-12；NACE Career & Self-Development/Professionalism；人社部 自我学习 | 事业三件套 |

**为什么是六维而不是五维或八维**：六维可以干净地切成"学业三件套 / 事业三件套"，主标签因此天然由雷达图的两组子指数之差决定，不必再引入自评；雷达图六轴在视觉上也比八轴清晰。八维（CEEAA 全部可观测项 + 人社部八项）能做，但其中至少三项（工程与社会、环境与可持续发展、职业规范）本平台**没有任何证据源**，加进来只会得到三个永远停在先验值的空轴。

**与旧五维的映射**（便于迁移）：

| 旧维 | 去向 |
|---|---|
| foundation 专业基础 | → D1（收窄为纯知识，去掉"基础好就推理好"的隐含假设） |
| research 科研 | → D4，但**不再由主标签分支公式生成**，改为由论文/课题组/学术词证据生成 |
| practice 实践 | → D3（明确为"工具与落地"，不是旧式泛化实践） |
| communication 沟通 | → D5 的一半（合并协作） |
| driveself 自驱 | → D6 的一部分（D6 还含守时、规划、复盘等可观测行为） |

## 4. 证据映射总表

统一换算框架：

```
观测 → 原始分 raw ∈ [0,1] → 维度分 s = 1 + 4 × raw （即 1~5 分）
维度分合成：D = Σ(w_i × s_i × decay_i) / Σ(w_i × decay_i)   ← 只用"已观测"的证据
置信度：   conf(D) = Σ(w_i × decay_i) / Σ(w_i)               ← 缺失证据不惩罚，但拉低置信度
```

四类 raw 的取值规则：

| 证据类型 | raw 计算 | 满分参照 |
|---|---|---|
| 比率型（得分率、完成率、准时率） | `raw = ratio` | 100% → 1.0 |
| 计数型（上传数、参与数、提问数） | `raw = log(1+n) / log(1+n_ref)` | `n_ref = 5`（5 次即满分） |
| 命中型（关键词命中） | `raw = min(1, hits / hits_ref)`，加权 Bloom 系数 | `hits_ref = 4` |
| 连续型（GPA） | 分段线性，见下 | — |

### 4.0 词典分级与命中型归一（2026-10-05 生成测试数据后修正）

生成三名测试学生时暴露了两个缺陷，规则已按以下方式修正：

**① 强弱词分级。** 初版词典把"比较""关系""如果""计划""沟通"这类高频口语词与"推导""反例""消融""我们组"同等计分，结果高远航只因 3 次口语"比较"就把 D2 顶到 4.48（而他其实不是分析推理型）。现分为两级：

- **强词（系数 1.0）**：明确指向该维度的行为词。例：为什么、推导、反例、边界条件、复杂度、消融、对照组、我们组、分工、复盘、周计划、Docker、压测。
- **弱词（系数 0.4）**：高频口语，只能作旁证。例：比较、关系、如果、区别、实现、版本、指标、改进、沟通、反馈、计划、目标、总结、下一步。

**② 零命中下限 0.2。** 初版"零命中 → raw=0 → s=1.0"，等于断言"没提问过这类问题 = 能力为零"，把苏明哲的 D3/D5 压到 1.53/1.77。现改为：

```
raw = 0.2 + 0.8 × clamp(Σ(命中词 × Bloom系数) / 6, 0, 1)
```

即零命中记 s=1.80（偏弱），命中约 6 个强词才满分。

**③ 满分参照 6（原为 4）**，并按 Bloom 加权后**一次性 clamp**（初版是逐条 clamp 再累加，3 条弱词就能逼近满分）。

完整词典见 `.tmp/_gen_profile_v2_data.py` 的 `LEX`（强/弱两级，可直接落库）。

**D5 关键词词典**：我们组、分工、我负责、汇报、讲给、听众、怎么表达、沟通、意见不合、协调、leader、例会、答辩、队友、配合、对接、评审、反馈、说服、写文档、进度同步、谁来做、一起
英文：team、standup、sync、align、review、feedback、retrospective、collaborate

### 4.6 D6 自主发展

| 编号 | 证据源 | 权重 w | raw 计算 |
|---|---|---|---|
| E6.1 | 任务完成率（`tasks.status=done / total`） | **0.30** | `raw = 完成率` |
| E6.2 | 准时率（1 − `homework_submissions.late` 占比） | **0.20** | `raw = 准时率`；零提交样本不计入 |
| E6.3 | 主动上传资料（`materials.owner_id=本人`） | **0.15** | `raw = log(1+n)/log(6)` |
| E6.4 | 复盘/规划词命中 | **0.20** | `raw = min(1, hits / 4)` |
| E6.5 | **自评**（`research_intent` / `job_intent`） | **0.15** | `raw = (intent − 1) / 4` |

> **E6.5 是唯一保留自评的地方，也是唯一的让步**：自评只在"自主发展"这一维占 15%，且**不参与主标签与 ABC 的任何直接判定**。理由：学生的自我期待确实反映了其自我驱动的意愿强度（这是自评唯一有预测力的地方），但它不能作为"你适合科研还是就业"的判据。

**D6 关键词词典**：复盘、计划、我该怎么学、从哪里开始、长期、规划、坚持、每天、目标、进展、习惯、自律、拖延、时间管理、周计划、下一步、路线图、自查、总结、给自己定
英文：roadmap、plan、habit、procrastinate、weekly、retro、goal

### 4.7 时间衰减与冷启动

- **衰减**：所有证据按 EMA 加权，`decay = 0.5^(Δt / 90)`，半衰期 90 天（约一学期）。避免大三的画像还主要由大一的作业决定。
- **冷启动**：某维度无任何观测 → `D = 3.0`（先验）、`conf = 0`，界面显示"待积累"而非 3.0 分。
- **整体置信度**：`conf_overall = Σ(w_i × conf(D_i)) / Σ(w_i)`，其中知识与分析类权重更高。

## 5. 六维 → 主标签（学业型 / 事业型）

### 5.1 子指数

```
S_acad   = 0.45×D1 + 0.35×D2 + 0.20×D4      （知识 · 推理 · 研究）
S_career = 0.40×D3 + 0.35×D5 + 0.25×D6      （工具 · 协作 · 自主发展）
Δ = S_acad − S_career
```

权重理由：学业侧以"知识—推理—研究"为核心链条（CEEAA 1→2→4），事业侧以"工具落地—团队协作—自我经营"为核心链条（NACE Technology/Teamwork/Career & Self-Development）。D6 归事业侧是依据 NACE 把 Career & Self-Development 明确列为就业胜任力；学业侧的"终身学习"（CEEAA-12）在本科阶段主要由科研训练体现，已计入 D4。

**D6 归属的敏感性已验证**：把 D2 的 15% 权重借给事业侧（即事业侧也吃分析推理），72 人合成样本中主标签判定变化 **7.9%**。说明这个归属不是无关紧要的，但也不至于颠覆结果——建议在评审时明确说明这一取舍。

### 5.2 判定规则（θ = 0.15，滞回 0.15）

| 条件 | 结果 |
|---|---|
| `Δ ≥ +0.15` | 学业型 |
| `Δ ≤ −0.15` | 事业型 |
| `|Δ| < 0.15` | **待定（双轨并进）** |
| `conf_overall < 0.50` | 强制"待定"，标注"数据不足" |
| 已有标签，反向切换 | 需越过 `∓(θ + 0.15) = ∓0.30` 才切换（滞回） |
| 标签变更 14 天内 | 不再回退（冷却期） |

**为什么引入"待定"**：强制二元划分会让 Δ≈0 的学生被随机推到某一侧，而这类人恰恰是最需要"两条路都给"的。合成推演中 |Δ|<0.15 的人占 **21.2%**，不是小众。

### 5.3 θ 的标定（4000 人合成样本）

| θ | 学业型 | 事业型 | 待定 |
|---|---|---|---|
| 0.10 | 43.0% | 43.5% | 13.6% |
| **0.15** | **39.8%** | **39.9%** | **20.4%** |
| 0.20 | 36.1% | 36.8% | 27.1% |
| 0.25 | 32.9% | 33.8% | 33.4% |
| 0.30 | 30.1% | 31.0% | 38.8% |

取 **θ=0.15**：待定率约 20%（合理，不强行贴标签），两侧对称（39.8% / 39.9%）。

### 5.4 滞回有效性（3000 人 × 6 次重算，每轮观测噪声 ±0.25）

| | 平均切换次数/人 | 至少切换 1 次的人占比 |
|---|---|---|
| 无滞回 | **1.587** | **52.1%** |
| 滞回 +0.15 | **0.271** | **21.6%** |

滞回把抖动降到约 **1/6**。没有它，学生每交一份作业画像就可能翻面。

## 6. 六维 → ABC 层次

### 6.1 轨道内分层分

```
学业型：L = 0.45×D1 + 0.30×D2 + 0.25×D4
事业型：L = 0.40×D3 + 0.35×D5 + 0.25×D6
待定  ：L = 六维均值
```

注意：主标签定轨后，**只在该轨道的三件套内评分**。一个"会考试不会动手"的学生在学业轨可能是 A，在事业轨就是 C——这比用 GPA 一刀切更接近真实，也更符合"分层只决定推荐内容深度"的定位。

### 6.2 分档规则（常模分位为主 + 绝对底线兜底）

1. **常模分位**：`A = L ≥ PR75`，`B = PR25 ≤ L < PR75`，`C = L < PR25`（同届同专业内排序）。
2. **绝对底线**：`D1 < 2.4` 时**一律不得评 A**（防止"活跃但知识不过关"被抬到 A）。
3. **置信度门槛**：`conf_overall < 0.50` 时不给字母，显示"**待评估**"。
4. **重标定周期**：每学期初用真实重算一次分位线，写进配置，不写死在代码里。

### 6.2.1 分层线必须**分轨道**标定（2026-10-05 修正）

初版把学业轨、事业轨、待定轨的分层分混在一个分布里取 PR75/PR25，得到单一绝对线（A≥3.64 / B≥3.17）。但三条轨道的分是**不同维度组合**算出来的，分布并不相同——混在一起取分位会给某一轨系统性偏高、另一轨系统性偏低。

修正：**学业轨、事业轨各算一套 PR75/PR25**，待定轨（六维均值）单独一套。当前合成标定值（A≥3.64 / B≥3.17）只能作为**临时线**使用，正式上线必须分轨重算。

### 6.3 为什么用常模而不是拍绝对线（关键教训）

第一轮设计里我拍了绝对阈值 A≥4.2 / B≥3.4，结果在合成样本上得到 **A 1.6% / B 48.9% / C 49.5%**——一半人被判 C，完全不可用。原因是维度分实际集中在 3.2±0.65，绝对阈值必须依据**实测分布**标定。改用常模分位后：

| 方案 | A | B | C | 对应绝对线（本合成分布） |
|---|---|---|---|---|
| 前 25% 为 A / 后 30% 为 C | 23.8% | 46.2% | 30.0% | A≥3.64、B≥3.22 |
| **前 25% 为 A / 后 25% 为 C** | **23.8%** | **51.2%** | **25.0%** | **A≥3.64、B≥3.17** |
| 前 30% 为 A / 后 30% 为 C | 28.3% | 41.7% | 30.0% | A≥3.58、B≥3.22 |

**推荐 PR75 / PR25**。绝对线作为可解释的"参考值"展示给用户（"你的分层分 3.9，班级前 25%"），但判定逻辑以分位为准。

### 6.4 与旧口径的差异（72 人实测）

| 口径 | A | B | C |
|---|---|---|---|
| 旧（GPA ≥85 / ≥70） | 31% | 53% | 17% |
| 新（仅用 D1，其余维无证据） | 6% | 36% | 58% |

必须说明：**这个对比不是为了说明新口径更严**，而是证明"只靠 GPA 换算出来的维度分不足以支撑分层"——新口径上线必须先把 D2~D6 的数据补上，否则会出现 58% 的人被判 C 的荒谬结果。这也是下一节路线图存在的原因。

## 10. 风险与局限（诚实版）

1. **所有阈值都是合成数据标定的**。θ、滞回、PR 分位线都来自蒙特卡洛推演（六维按 N(3.2, 0.62) 抽样、组内相关 0.42）。真实学生分布一旦偏离，全部需要重标定。**上线前必须用真实学期数据重跑一次标定**。
2. **文本关键词法效度有限**。学生问"为什么"可能只是没听懂，不等于分析能力强。缓解：文本证据权重不超过该维度的 30%，且必须与作业要点命中率这类**结果性证据**搭配使用。
3. **D2/D4 的区分度依赖人工标注的要点**。如果教师布置作业时没有标注要点，`E2.2` 会失效，D2 将只剩文本证据。这是本方案最大的单点依赖。
4. **"待定"标签的商业风险**。20% 的学生画像显示"待定/待评估"，路演时可能被解读为"系统没算出来"。建议在界面上把它包装为正面表述："你目前是**双轨并进型**，两条路径的资源都会推荐给你"。
5. **公平性与贴标签风险照旧**。新口径依然只是"规则算出来的画像"，不是科学测评；CEEAA / 人社部框架提供的是**维度合法性**，不能提供**分数效度**。分层结论仍然只用于推荐内容深度与任务难度，**不得用于分班、评优、准入**——这条口径必须写进代码注释和界面 `PF.caveat`。
6. **CEEAA 有 5 条毕业要求本方案覆盖不到**（设计开发解决方案、工程与社会、环境与可持续发展、职业规范、项目管理）。若面向文科或非工科专业，还需另选框架（如 NSSE 学习投入度调查维度）。
